# Booking API

> ⚠️ Статус: в разработке. Функциональность и API могут меняться.

Backend-сервис на FastAPI для управления бронированиями столиков.

## Что делает

* Создаёт бронирование с валидацией данных клиента, даты, времени и количества гостей.
* Возвращает список существующих бронирований.
* Позволяет получить конкретное бронирование по ID.
* Позволяет отменить бронирование.
* Проверяет занятость выбранного временного слота.
* Поддерживает фильтрацию бронирований по дате.
* Автоматически предоставляет документацию Swagger/OpenAPI.

## Стек

* FastAPI — веб-фреймворк, обработка HTTP-запросов и REST API
* Pydantic — валидация входных и выходных данных
* Uvicorn — ASGI-сервер для запуска приложения
* Docker — контейнеризация и деплой приложения

## API

### Создание бронирования

```http
POST /bookings
```

Пример:

```json
{
    "name": "Иван Иванов",
    "phone": "+79261234567",
    "booking_date": "2026-09-15",
    "booking_time": "19:00",
    "guests": 4
}
```

### Получение бронирований

```http
GET /bookings
```

Можно передать дату для фильтрации:

```http
GET /bookings?date=2026-09-15
```

### Получение бронирования

```http
GET /bookings/{id}
```

### Отмена бронирования

```http
DELETE /bookings/{id}
```

Бронирование не удаляется физически — его статус изменяется на `canceled`.

## Валидация

* Имя — от 2 до 30 символов.
* Телефон — поддерживаются форматы `8XXXXXXXXXX` и `+7XXXXXXXXXX`.
* Дата бронирования — от текущей даты до 90 дней вперёд.
* Время — только доступные временные слоты.
* Количество гостей — от 1 до 12.
* Нельзя создать несколько активных бронирований на один временной слот.

При попытке занять уже существующий слот API возвращает:

```http
409 Conflict
```

## Настройка перед запуском

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
uvicorn main:app --reload
```

После запуска API будет доступен на:

```text
http://localhost:8000
```

## Сборка и запуск через Docker

Сборка образа:

```bash
docker build -t booking-api .
```

Запуск контейнера:

```bash
docker run -d --name booking-api -p 8000:8000 booking-api
```

Проверить, что контейнер запущен:

```bash
docker ps
```

Посмотреть логи:

```bash
docker logs -f booking-api
```

Остановить контейнер:

```bash
docker stop booking-api
```

## Хранение данных

В текущей версии бронирования хранятся в памяти приложения.

После перезапуска контейнера или приложения созданные бронирования будут потеряны.

В дальнейшем планируется добавить постоянное хранилище данных.
